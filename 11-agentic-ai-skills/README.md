# Module 11 — Agentic AI / Skills (agentskills.io)

## Overview

This module is a conceptual/design task (per curriculum) documenting an autonomous tool-calling decision tree for an agentic AI system: how an agent evaluates a task, selects between available tools (vector search, web search, internal database), evaluates results, and synthesizes a final response.

## Deliverable

See `DESIGN.md` for the full decision-tree diagram and step-by-step breakdown, contextualized to the JourneyBuddy Intelligent Assistant System (the final integration project).

## Key Concepts Covered

- The Plan → Act → Observe → Iterate agentic feedback loop
- Tool selection logic: vector search vs. web search vs. internal database
- Result evaluation and retry/fallback strategy
- Final response synthesis grounded in retrieved context
